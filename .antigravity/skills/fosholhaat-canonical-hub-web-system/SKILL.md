- `coordination-first command surface`
- `adjacent operational visibility`

Reject prompt language that implies:

- ERP control room
- giant KPI dashboard

- seller operations desk

## Candidate Review Heuristics

Treat a Hub desktop candidate as suspect if it shows:

- center-body emptiness that makes the shell feel unfinished
- isolated modules with poor cross-operation visibility
- over-red alert walls
- redundant command controls
- boxy harsh control-room geometry
- panels that monitor metrics but do not improve action readiness
